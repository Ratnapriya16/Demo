# 📄 HTML Forms Project

This project showcases simple HTML-based form designs for user registration and a class timetable. It is useful for learning basic HTML form elements, structure, and layout.

## 🌐 Project Overview

### ✅ Forms Included:
- **Registration Form** – Collects user details like name, email, gender, etc.
- **Timetable Form** – A table layout to display or edit a weekly class schedule.

## 🧩 Technologies Used

- HTML5
- Basic CSS (optional)
